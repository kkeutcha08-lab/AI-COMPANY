# ACCOUNTS

Registre central des comptes de l'entreprise.

Chaque compte contient :
- plateforme ;
- identifiant interne ;
- niche ;
- objectif ;
- statut ;
- audience ;
- performances ;
- stratégie de contenu ;
- historique des décisions.

Les informations sensibles et identifiants de connexion ne doivent jamais être enregistrés dans ce dossier.
